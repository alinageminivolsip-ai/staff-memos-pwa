О приложении

Это простое PWA-приложение для памяток. Его можно открыть по ссылке и добавить на экран iPhone.

iPhone: открой ссылку в Safari → Поделиться → На экран Домой → Добавить.

Чтобы заменить тексты, открой файл index.html и найди блок const MEMOS.
